## Requirements
Smart Filemanager is 100% python-based program. The main modules are as follows:
- PyQt
- watchdog
- openai

## Installation
### Prerequisites
- Python > 3.9
- Windows 10/11 

### Install the dependencies

```
pip install watchdog
pip install openai
pip install tkinter
pip install pyqt5
...
```

#### Execute the source code

```sh
python main.py
```
