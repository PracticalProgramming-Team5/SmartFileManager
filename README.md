## Requirements
Smart Filemanager is 100% python-based program. The main modules are as follows:
- tkinter / PyQt
- watchdog
- openai

## Installation
### Prerequisites
- Python > 3.9
- Windows 10/11 

### Install the dependencies

```
pip install -r requirements.txt
pip install watchdog
pip install openai
pip install tkinter
pip install pyqt
```

#### Execute the source code

```sh
python main.py
```
